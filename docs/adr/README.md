# Architecture Decision Records

Registro imutável das decisões estruturais do RoHair.

## Regras

- Um ADR por decisão estrutural (arquitetura, dado, segurança, infraestrutura).
- ADR **nunca é editado** depois de aceito. Mudou de ideia? Cria-se um novo ADR
  com status `Substitui ADR-XXXX`, e o antigo passa a `Substituído por ADR-YYYY`.
- Decisões menores vivem em [../04-DECISOES.md](../04-DECISOES.md).

## Formato

Numeração sequencial: `ADR-0001-titulo-em-kebab-case.md`.
Use o [TEMPLATE.md](TEMPLATE.md).
